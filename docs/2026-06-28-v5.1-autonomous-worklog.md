## 一、我自主做的决策（用户休息期间）

| # | 决策点 | 我的选择 | 理由 |
|---|---|---|---|
| D1 | 基本面数据源 | akshare(`stock_zh_valuation_baidu` 取 PE/PB,`stock_financial_analysis_indicator` 取 ROE),弃用 Desktop `_basic/_fina`(只几百只) | 全市场覆盖 |

| D3 | Spearman IC 实现 | 不引入 scipy,改用「对秩做 Pearson」(数学等价) | 避免重依赖 |
| D4 | factor_panel 不存前向标签 | 前向收益只在 IC 模块内算,不写进特征表 | 防止下游误用未来数据泄漏 |
| D5 | 旧 Desktop 稀疏估值表 | 删除(只几百只、schema 不符),改等 B1 akshare 全量 | 统一 schema、全市场覆盖 |
| D6 | factor_backtest 改动方式 | 全部新增可选参数(weights_provider/risk/return_equity_curve),默认行为不变 | 不破坏现有 108 个测试 |
| D7 | HPO 只调结构参数 | 多目标 HPO 只搜 top_n/rebalance,**不搜因子权重**(权重来自 IC) | 落实「避开 3fopt 过拟合」决策 |
| D8 | null test 判据 | 用「策略自身 dev 收益」作门槛,问随机因子能否达到 | 否则 0 收益门槛让 null test 失效 |
| D9 | B2/B3 网络拉取时机 | 延到 B1 基本面跑完再拉,不并发 | 避免 8 线程已占满网络时再加载导致互相限流 |
| D10 | ST 历史 | akshare 无免费历史 ST,只能取**当前** ST,标注为近似 | 诚实标注限制(见遗留) |
| D11 | 真实数据先不接基准跑通 | 端到端 smoke 先 benchmark=None(网络被 B1 占),验证引擎 | 不阻塞;基准门禁逻辑已测 |
