# 工作流

## 阶段

1. KPI 录入
2. 记忆召回
3. 研究产出策略说明
4. 定义数据需求
5. 数据收集与口径确认
6. 量化工程实现
7. 回测与风控审核
8. 人工审批
9. 手动监控与推送
10. 记忆沉淀

## 核心要求

- 研究阶段必须先回答“为什么这个策略在当前市场可能有效”
- 数据阶段必须回答“回测所需数据是否可获得、可对齐、可审计”
- 回测阶段必须回答“是否存在未来函数风险、是否满足最大回撤限制”
- 监控阶段必须支持零信号说明

## 自动放宽门槛

- 顺序：先降年化，再降胜率
- 最低线：年化 `>= 5%`，胜率 `>= 80%`
- 仍不满足时，输出最优未达标方案与差距说明
