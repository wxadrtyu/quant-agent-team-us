# 虚拟实盘操作规格文件

> 本文件为虚拟实盘模拟的**标准操作规范**，以后所有虚拟实盘操作均按此执行，不得随意变更。

## 一、三大分类维度

策略分类合并为以下三大类，**不再区分有止损/无止损**：

| 维度 | 分类 | 说明 |
|------|------|------|
| 持仓数量 | N30 / N10 / N7 / N5 | 实际持仓数由HPO决定（N30→20-30只, N10→5-10只, N7→5-7只, N5→3-5只） |
| 加权方式 | 等权 / 非等权 | 等权=1/n均分; 非等权含HR11(前半1.1x后半0.9x)、反波动率(1/vol_20d) |
| MDD约束 | 低MDD / 非低MDD | 低MDD: N30约束≤25%, N10/N5约束≤20%; 非低MDD: 无约束(1.0) |

**组合分类**：4×2×2 = 16个分类。实盘池里有什么就实盘什么，不截断、不筛选、不淘汰：ALL_POOLS中列出的所有策略全部参与实盘，每类不限制数量，新策略加入不影响已有策略。

## 二、入选标准

策略进入实盘池后即参与实盘，不再按分类截断排名。

入选前提：
- 策略已存入 `live_pool_strategies` 表（quant.duckdb）
- 状态为 `active`
- 有明确的因子组合和4种子回测结果
- 未被标记为"否决"或"待验证"

优秀策略标准（参考，非强制门槛）：
- IR > 1.3
- MDD < 20%
- OOS > 300%
- 4种子全部 IR > 1.0

当前实盘池共 64 个策略，其中 23 个优秀策略（含 dd10+AMP+VMR 等权/非等权、dd3/dd10+AMP+VMR、dd8/dd10+CMF20+DIF、dd10+CMF20+DIF+VMR 等因子组合，加权方式含等权/hybrid_ratio/inv_vol/inv_vol_hr12），涵盖 N5/N7/N10/N30 四种持仓分类。

## 三、模拟实盘流程

### 3.1 时间安排
- **信号日**：每月最后一个交易日（或指定日期）
- **估值日**：信号日次日
- **买入价**：信号日收盘价（复权）
- **估值价**：估值日收盘价（复权）

### 3.2 信号生成（无前视）
1. 因子面板数据截至信号日（不含估值日数据）
2. IC自适应权重：24月lookback计算IC，shift 20天确保无前视
3. HPO搜索：24月lookback训练，3折walk-forward，9 trials NSGA-II
4. HPO空间：
   - N30: top_n=[20,30], rebalance=[5,10,20]
   - N10: top_n=[5,10], rebalance=[5,10,20]
   - N5: top_n=[3,5], rebalance=[5,10,20]
5. 选股：信号日综合得分排名，取top_n只

### 3.3 加权方案
- **等权**：1/n
- **HR11**：前半1.1x，后半0.9x（hybrid_ratio, alpha=1.1）
- **反波动率**：1/vol_20d

### 3.4 盈亏计算
- 个股收益 = 估值价 / 买入价 - 1
- 策略收益 = Σ(权重 × 个股收益)
- 超额收益 = 策略收益 - HS300基准收益
- 每策略本金：¥300,000
- 止损策略：1日持仓不触发（需+15%涨幅才启动止损逻辑）

## 四、报告字段

### 4.1 策略级字段
| 字段 | 说明 |
|------|------|
| 策略ID | 唯一标识 |
| 中文标签 | 买入N只+加权+MDD级别+因子简称 |
| 分类 | N30/N10/N5-等权/非等权-低MDD/非低MDD |
| 因子 | 逗号分隔的因子列表 |
| top_n | HPO选出的实际持仓数 |
| 加权方式 | equal / HR11 / inv_vol |
| MDD约束 | 低(0.25/0.20) / 非低(1.0) |
| HPO OOS | 训练期样本外收益 |
| HPO MDD | 训练期最大回撤 |
| 持仓数 | 实际选出的股票数量 |
| 策略收益 | 信号日→估值日收益 |
| 超额收益 | 策略收益 - HS300 |

### 4.2 个股级字段
| 字段 | 说明 |
|------|------|
| 排名 | 综合得分排名 |
| 代码 | 股票代码 |
| 名称 | 股票名称 |
| 权重 | 在组合中的权重 |
| 买入价 | 信号日复权收盘价 |
| 估值价 | 估值日复权收盘价 |
| 个股收益 | 估值价/买入价-1 |
| 收益贡献 | 权重 × 个股收益 |
| 得分 | 综合因子得分 |

### 4.3 汇总统计
- 策略总数、盈利数、亏损数、平均收益、跑赢基准数
- 按分类汇总（每类的平均/最佳/最差收益）
- 共识股票（被3个以上策略选中的股票）
- 所有唯一股票盈亏汇总（按平均收益排序）

## 五、HTML报告格式

- **策略ID前缀**：所有策略ID前标注持仓类别（N30-xxx / N10-xxx / N5-xxx）
- **排序规则**：全局表按 N30→N10→N5 分组，组内按回测IR从高到低排序
- **分类汇总**：同样按 N30→N10→N5, 组内按等权→非等权, 低MDD→非低MDD 排序
- **个股明细**：按持仓分组展示，每组有醒目标题栏（N30蓝色/N10绿色/N5橙色）
- 每个策略的个股明细全部直接展示，不折叠
- 所有唯一股票盈亏汇总表（按平均收益排序）
- 颜色：盈利绿色，亏损红色
